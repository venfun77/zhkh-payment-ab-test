# A/B-тест формы оплаты ЖКХ

Проверка новой формы с автозаполнением реквизитов. Цель: оценить изменение доли уникальных пользователей, совершивших хотя бы одну успешную оплату.

**Данные:** 1500 пользователей в анализе, по 750 в A и B. В основном расчёте исключён пользователь 1010 из-за конфликта назначения группы.

**Результат:** конверсия A 65,73%, B 80,40%. Абсолютный прирост +14,67 п.п., относительный +22,31%. Односторонний z-тест, p < 0,001, уровень значимости 5%.

Что есть в ноутбуке: проверка данных, воронка, доверительные интервалы, баланс групп, сегменты, стандартизация, анализ времени и дневной динамики.

## Запуск

1. Скачать Excel из [исходного задания](https://edu.tbank.ru/files/cebbefc3-5b29-4f88-b6d4-3336c88d743f).
2. Положить файл рядом с ноутбуком под именем `dannye-dlia-keisa-po-pa-cebbefc3-5b29-4f88-b6d4-3336c88d743f.xlsx`.
3. Установить зависимости: `pip install -r requirements.txt`.
4. Запустить `AB_ZHKH_analysis.ipynb` сверху вниз.

Данные в репозиторий не включены.

Полный отчёт: `report.pdf`.
